# Support & tickets

Besoin d'aide, envie de faire débloquer un module ou question sur votre
licence ? Vous pouvez joindre l'exploitant de la plateforme directement
depuis l'application — sans passer par l'e-mail.

## Ouvrir un ticket

1. Allez dans **Admin → Support**.
2. Cliquez sur **Nouveau ticket**.
3. Saisissez un **sujet** court et votre **message**, puis **Envoyer**.

Votre ticket apparaît dans la liste et ouvre un fil de conversation.

## Échanger sur un ticket

- Cliquez sur le sujet d'un ticket pour ouvrir la **conversation**.
- Écrivez dans le champ en bas et appuyez sur **Entrée** (ou sur le bouton
  d'envoi) pour répondre.
- Le fil est **en direct** — les nouvelles réponses de l'équipe opérateur
  apparaissent automatiquement en quelques secondes, sans recharger la
  page. Vous pouvez garder le ticket ouvert dans un onglet et voir les
  réponses arriver.
- Les messages de l'équipe opérateur sont marqués **Équipe opérateur** ;
  vos propres messages s'affichent à droite.

## Statut

- **Ouvert** — la conversation est active.
- **Fermé** — l'exploitant l'a marqué comme résolu. Si vous répondez à un
  ticket fermé, il est automatiquement rouvert.

## Ce que le support peut (et ne peut pas) voir

Les tickets de support sont le seul canal par lequel vous communiquez
*avec nous* ; l'équipe opérateur peut donc lire le texte des tickets que
vous rédigez ici.

Elle **ne peut pas** voir vos données d'enquête — dossiers, entités,
résultats de recherche, alertes et vos comptes utilisateurs restent
entièrement dans votre propre système. Le support ne voit jamais que ce
que vous saisissez dans un ticket. Veuillez ne pas coller de contenu
sensible d'un dossier dans un ticket ; décrivez plutôt le problème.

## Demandes typiques

- « Merci d'activer le module *crypto* pour nous. »
- « Notre data-agent semble injoignable — pouvez-vous vérifier ? »
- « Nous aimerions ajouter un compte d'enquêteur supplémentaire. »
- « Question sur l'échéance de notre licence. »

> Conseil : les modules que vous pouvez utiliser dépendent de votre
> **licence**. Si une recherche indique *« Aucun module disponible pour le
> type … »*, votre organisation n'a peut-être pas de licence pour un module
> couvrant ce type — ouvrez un ticket et demandez.
